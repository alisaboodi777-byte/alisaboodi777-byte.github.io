Projects

03 selected works
Project 01 Capstone

Mortgage Denial Risk Prediction

An end-to-end machine learning project on a real-world Washington State mortgage lending dataset (HMDA, 2024), built to help a simulated lending institution flag high-risk applications before manual underwriting review. Cleaned and validated 197,000+ raw records — resolving anomalous income values, extreme loan-amount outliers and missing data — then benchmarked five classification algorithms and tuned the top performers to optimize recall on denied applications. Findings were delivered through a stakeholder-facing presentation and infographic translating model performance into business impact, limitations and next steps.

Python scikit-learn XGBoost CatBoost Random Forest Pandas GridSearchCV
Project 02

Startup Funding EDA — Crunchbase

A full exploratory data analysis on a Crunchbase startup funding dataset to help a simulated venture capital firm refine its seed-stage investment criteria. Cleaned and validated the raw data, corrected a data-aggregation error in total funding calculations, and engineered features to track funding-stage progression and follow-on outcomes — surfacing which startup characteristics were most associated with securing follow-on funding.

Python Pandas Matplotlib Seaborn Jupyter
Project 03

Investment Portfolio Optimization

Developed and optimized a $1M diversified investment portfolio using Modern Portfolio Theory, Markowitz Mean-Variance Optimization, CAPM and Excel Solver. Conducted security selection, asset allocation and performance evaluation using Sharpe Ratio, beta, Jensen's Alpha and standard deviation — comparing passive optimization against active trading strategies to reach the client's optimized allocation.

Excel Solver Modern Portfolio Theory CAPM Risk Metrics
